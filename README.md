# integ

## Overview
This is the `dampbrownshoes/integ` repository - a demonstration repository.

## What This Repository Shows
This repository demonstrates the capabilities of GitHub Copilot Coding Agent:

### ✅ Things I Can Do:
1. **Code Search** - Find code using grep and glob patterns
2. **Code Modification** - Create, edit, and update files
3. **Testing** - Run tests, builds, and linters
4. **GitHub Integration** - Create PRs, view actions, search issues
5. **Security Scanning** - CodeQL analysis and vulnerability detection

### 🔍 Code Search Example
I can search for code patterns across files:
```bash
# Search for text in files
grep -r "pattern" .

# Find files by name
find . -name "*.js"
```
