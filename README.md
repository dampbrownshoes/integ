# integ

## Sign In Feature

This repository contains a simple, standalone sign-in page implementation.

### Features

- Clean and modern UI with gradient background
- Client-side form validation
- Real-time error messages
- Responsive design that works on all devices
- Username and password fields with validation rules:
  - Username: minimum 3 characters
  - Password: minimum 6 characters

### How to Use

1. Open `signin.html` in your web browser
2. Enter a username (at least 3 characters)
3. Enter a password (at least 6 characters)
4. Click "Sign In" button

The page includes form validation that will display error messages if the input doesn't meet the requirements.

### Demo

Simply open the `signin.html` file in any modern web browser to see the sign-in page in action.
