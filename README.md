# Integ - Sign In System

A simple, responsive web-based sign-in system built with HTML, CSS, and JavaScript.

## Features

- Clean, modern user interface
- Responsive design (mobile and desktop)
- Form validation
- Error handling
- Session management with localStorage
- Demo authentication system

## How to Use

1. Open `index.html` in a web browser
2. Enter one of the demo credentials above
3. Click "Sign In" to access the welcome page
4. Use "Sign Out" to return to the sign-in form

## Files

- `index.html` - Main sign-in page
- `styles.css` - Styling and responsive design
- `script.js` - Authentication logic and form handling

## Security Note

This is a demo implementation using client-side storage and hardcoded credentials. In a production environment, authentication should be handled securely on the server side with proper encryption and security measures.
