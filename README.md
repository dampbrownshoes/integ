# integ

## Sign In Feature

This repository contains a simple sign-in page implementation.

### Files

- `signin.html` - Main HTML page with sign-in form
- `styles.css` - Styling for the sign-in page
- `signin.js` - JavaScript for form validation and handling

### Usage

To use the sign-in page, simply open `signin.html` in a web browser.

### Features

- Username and password input fields
- Form validation (minimum 6 characters for password)
- Success/error message display
- Responsive design
- Modern UI with gradient background
