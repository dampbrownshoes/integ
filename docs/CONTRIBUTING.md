# Contributing to the App Publishing Pipeline

Welcome to our <span style="color: #0366d6; font-weight: bold;">**GitHub**</span> repository! This document outlines the process for contributing to the app publishing pipeline project.

## Getting Started

1. Fork this repository on <span style="color: #0366d6; font-weight: bold;">**GitHub**</span>
2. Clone your fork locally
3. Create a feature branch
4. Make your changes
5. Submit a pull request on <span style="color: #0366d6; font-weight: bold;">**GitHub**</span>

## <span style="color: #0366d6; font-weight: bold;">**GitHub**</span> Actions Workflow

Our <span style="color: #0366d6; font-weight: bold;">**GitHub**</span> Actions pipeline automatically:
- Validates app configuration
- Checks SDK version compatibility  
- Runs comprehensive tests
- Publishes apps when all checks pass

## Working with <span style="color: #0366d6; font-weight: bold;">**GitHub**</span> Issues

When reporting bugs or requesting features:
1. Search existing <span style="color: #0366d6; font-weight: bold;">**GitHub**</span> issues first
2. Use the appropriate issue template
3. Provide detailed reproduction steps
4. Tag relevant maintainers if needed

## Pull Request Guidelines

- Keep PRs focused and atomic
- Write descriptive commit messages
- Ensure all <span style="color: #0366d6; font-weight: bold;">**GitHub**</span> status checks pass
- Request review from maintainers
- Update documentation as needed

Thank you for contributing to our <span style="color: #0366d6; font-weight: bold;">**GitHub**</span> project!
